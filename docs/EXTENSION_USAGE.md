# BOSS / 猎聘扩展使用说明

[English](EXTENSION_USAGE.en.md) · [项目说明](../README.md)

当前任务的完成定义：对明确符合“北京、AI 与产品工作相关”的岗位，BOSS 扩展在详情页点击一次“立即沟通”；猎聘扩展先打开职位明细，再点击右上角一次“聊一聊”，然后关闭明细。账本显示“已点击·待人工确认”。会话、默认招呼和简历状态随后由你人工检查；扩展不自动发送简历，也不重复点击历史已处理或结果未知的岗位。

## 安装与首次连接

1. 在项目目录运行 `npm run build`，并启动本机服务 `docker compose up -d --build --wait`。打开 [本机工作台](http://127.0.0.1:17830) 检查服务可用。
2. Chrome 打开 `chrome://extensions`，开启“开发者模式”，点“加载已解压的扩展程序”，选择项目内 `dist/extension`。若之前已安装，点击该扩展卡片的“重新加载”，再刷新已打开的 BOSS / 猎聘职位标签页。猎聘真实点击需要 Chrome 的 `debugger` 权限：这是浏览器级权限，安装详情会提示可读取和更改各网站数据；本项目代码只在已核对的猎聘职位页及明细页发送鼠标事件，用后立即断开。请在授予前确认扩展来源是本项目构建目录。
3. 在工作台“连接设置”生成一次性配对码，在扩展弹窗“连接本机服务”中输入。弹窗顶部应显示“已配对·本机执行”。
4. 登录 BOSS，在弹窗点击“打开配置的 BOSS 北京搜索页”，或直接打开 `https://www.zhipin.com/web/geek/jobs?query=AI%E4%BA%A7%E5%93%81%E7%BB%8F%E7%90%86&city=101010100&industry=&position=`。保持这个标签页在前台，等左侧列表和右侧详情加载完成。

## 配置搜索页与点击间隔

扩展弹窗展开「搜索入口与点击间隔」。BOSS、猎聘各有一个 URL 输入框：只接受各自官网北京职位搜索页，城市不能更改，关键词可以改；BOSS 必须保留 `city=101010100`，猎聘必须保留 `city=010&dq=010`。搜索关键词只控制候选来源，自动判断仍要求岗位地点为北京且工作同时与 AI 和产品有关。填写完整 URL 后，设置「两次沟通点击的最短间隔」为 **5–120 秒整数**（默认 5 秒），点「保存设置」。页面提示已保存后，使用弹窗中的「打开配置的…搜索页」，或手动打开相同 URL，刷新招聘标签页。修改搜索入口时，运行中的批次须先暂停或停止，并等待已领取动作结束；暂停的批次在配置变化后须重新核对并续接。新设置不会改写历史记录。

点击间隔按每轮启动时的值保存在本机服务端。连续两次真实沟通点击之间、以及同一账号开始下一轮时，服务端再次校验间隔；弹窗显示本轮间隔与剩余等待时间。该设置是本机节流，不保证招聘平台不施加限制。

## 执行

选择“当前页 · BOSS”连接。首次可先点“只读取与判断”检查岗位范围；它会切换左侧岗位并读取右侧详情，不点击“立即沟通”。若要只处理当前选中岗位，点“点击当前岗位一次”；若要自动逐岗处理，设置本轮合格岗位上限和分钟数，再点“开始自动点击立即沟通”。两种点击操作都可能发送 BOSS 默认招呼。

自动任务在当前已打开的搜索页循环读取左侧岗位：选中一条、核对右侧详情、判断是否符合北京 AI 产品工作范围，再对合格且未处理的岗位点击一次“立即沟通”。处理完已加载岗位后会尝试滚动加载下一批；达到岗位上限、时间上限、列表终点或连续两次滚动无新岗位时结束。本轮不会在结束后常驻监控新发布岗位，也不会自动刷新整个网页。关闭扩展弹窗不影响正在运行的任务，但职位标签页需要保持前台。

每次“立即沟通”点击收到本机回执后，扩展按本轮设置等待 5–120 秒再继续处理下一岗位；同一账号紧接着启动新批次也会按新批次间隔核对历史点击。弹窗会显示剩余等待秒数。若点击结果不明，任务会暂停并要求人工核对，不会在等待结束后重试。所设间隔只是本机节流设置，不能保证平台不触发限制；遇到平台检查仍需人工处理。

去重按同一 BOSS 账号和岗位 ID 跨批次保存：本机已有点击、结果未知或已沟通记录的岗位会在选择前跳过，不占本轮新岗位上限；点击前服务端还会核对历史命令。若 BOSS 当前详情显示“已沟通”或“继续沟通”，也会跳过。平台若对扩展使用前的人工旧会话仍显示“立即沟通”，且页面不提供可核对的岗位 ID，扩展无法可靠识别该旧会话；这类历史岗位需人工核对，不能把页面按钮当作没有沟通过的证明。

BOSS 在点击后弹出“已向BOSS发送消息”时，扩展会在本岗位动作结束前选择“留在此页”关闭提示，包括本轮最后一个岗位；然后继续下一岗位或结束本轮。正常批次不需要每岗点一次“继续”。若弹层与已验证结构不同，扩展保留本岗位“已点击”记录并暂停，请人工核对；“继续本轮自动点击”只用于登录、未知弹层、页面变化或结果不明等异常中断后的人工接管。

扩展仅对明确符合范围、左右岗位身份一致、按钮确为“立即沟通”的岗位动作。标题不必精确等于“AI产品经理”；职责必须同时涉及 AI 与产品。遇到验证码、登录异常、账号变化、页面结构变化、用户操作接管或无法确认点击时会暂停。请在“岗位记录”和“执行记录”查看“已点击·待人工确认”和“结果未知”，并到 BOSS 人工确认会话/简历。

若 BOSS 页面 URL 出现 `_security_check` 等额外检查参数，扩展会把当前页视为非设定入口并禁止继续点击。按平台页面提示人工处理；页面正常恢复且扩展重新识别岗位列表后，才考虑续接暂停批次。

## 灰色按钮的含义

| 按钮 | 何时可用 |
| --- | --- |
| 暂停 / 接管、恢复、停止 | 只有本轮任务已启动且状态适合时才可用；“尚未启动”时灰色是正常状态。 |
| 只读取与判断 | 本机服务已配对、指定 BOSS 搜索页在线且可识别时可用。 |
| 点击当前岗位一次 | 同上，且选中岗位身份明确、当前适配器允许点击；已有点击或未决记录会被服务端拒绝。 |
| 开始自动点击立即沟通 | 同上，并且当前没有未结束任务；不要求先完成单岗位验证。 |
| 继续本轮自动点击 / 续接本轮自动点击 | 自动任务暂停时，主按钮会变为继续入口；扩展更新或本轮到期时先安全结束旧运行，再沿用已处理岗位记录开启新运行。存在本轮未知外部动作时仍会禁用。 |
| 续接上一批 | 只有上一批结束且当前无活动任务时可用。 |

如果所有启动按钮仍灰色：先检查弹窗是否“已配对”，是否选中了当前 BOSS 职位标签页，是否打开扩展中配置的完整搜索 URL；重新加载扩展后先打开弹窗；若当前受控页面仍为空或提示未连接，再刷新职位页。页面不在前台、账号头像无法识别、详情未同步或登录提示会在岗位标题下方给出原因。不要通过修改扩展配置或清空数据库来绕过原因；旧的结果未知岗位会自动跳过，其他岗位仍可新开任务。

看到“需接管”时，不代表扩展只能处理一个岗位。它表示原任务已暂停，因此只读扫描和新建任务暂时禁用。先读岗位标题下方的具体原因；若主按钮显示“继续本轮自动点击”或“续接本轮自动点击”，点击它才会继续处理剩余岗位。已点击的岗位保留去重，不会因续接再次点击。

若提示“左右岗位身份未同步”，先确认当前 BOSS 页面左侧高亮岗位与右侧详情一致、页面无弹层或平台检查，再从扩展明确点击“继续本轮自动点击”。恢复后会重新选择账本中尚未处理的岗位并核对 ID；仅当前页面恢复正常且核对通过时才可能继续点击“立即沟通”。若 URL 仍含 `_security_check`，先按 BOSS 页面提示人工处理，不要绕过检查续接。

## 猎聘使用

登录猎聘后，点击弹窗“打开配置的猎聘北京搜索页”，或打开 `https://www.liepin.com/zhaopin/?city=010&dq=010&key=ai%E4%BA%A7%E5%93%81%E7%BB%8F%E7%90%86&workYearCode=0&currentPage=0&pageSize=40`。原先不含 `city=010&dq=010` 的链接会显示全国岗位，不符合本轮范围。保持猎聘职位标签页在前台，等待列表出现，在“当前受控页面”选择“当前页 · 猎聘”。

设置岗位上限和分钟数，点“开始自动点击聊一聊”。扩展按页面顺序核对岗位 ID 与北京地点、判断 AI 产品相关性、跳过历史点击/结果未知/已沟通，再真实点击职位标题打开明细页，并点击明细页右上角的“聊一聊”。点击后必须看到“我的沟通”或按钮变成“继续聊”，然后关闭明细页，才进入下一岗。列表上的“继续聊”直接跳过。无响应、明细未打开、遮挡或页面变化则暂停。同一账号两次点击至少间隔本轮设置的 5–120 秒。

猎聘新版任务需要真实点击和可见页面响应才记 `CLICKED`，并不代表简历已经投递或招聘方已收到消息。请在猎聘会话中人工确认。若出现“结果未知”，不要点同一岗位补发；可在只读工作台按平台查看证据，核对招聘平台实际会话后在扩展的“登记结果未知的动作”中记录结论与依据。工作台不按当前标签页筛选，也不发起或处理任务。旧版 `liepin-click-v1` 曾把 DOM `.click()` 调用直接记作成功，用户已观察到部分岗位实际未打开沟通；旧版记录仍保留去重，须逐条人工核对。新版真实页面点击、浮层自动收尾和跨页批量运行仍需小批次验收。

若弹窗提示“当前招聘页面尚未就绪”，但岗位列表已经显示，先检查弹窗连接对应的适配版本。服务已更新而扩展仍为 `liepin-click-v1` 时，打开 `chrome://extensions`，在“Auto JB 本地求职助手”详情点击“重新加载”，回到猎聘搜索页刷新，待扩展重新连接后再打开弹窗。新版会明确提示旧扩展版本并禁用启动按钮；不要重复点旧版任务。

若已配对、页面可读，但启动时报“扩展与本机服务版本不一致”或提示服务不识别 `contact_interval_seconds`，说明扩展已更新而本机 Docker 后端仍是旧版。先停止当前批次，运行 `docker compose up -d --build --no-deps --wait app`，再在 `chrome://extensions` 重新加载扩展并刷新招聘页。更新前确认 `.env` 与正在运行的服务使用同一管理令牌；数据库卷应保留，不能通过清库处理版本不匹配。
